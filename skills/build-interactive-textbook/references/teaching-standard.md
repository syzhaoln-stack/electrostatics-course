# 教学与模型标准

这些是本工作流的制作与验收约定，不是国家或行业标准。课程大纲、教师要求、正式规范优先。

## 一张图的教学契约

图号、目标问题、前置知识、已知条件、允许操作、固定量、读数量纲、模型假设、正确关系、学生提交内容、核验方法缺一项就可能出现图题脱节。没有原题时明确标注自编样题。

默认从一个概念和一个可辨认操作开始。“路径无关”就固定端点与电场，只改路径；比较电荷量就固定几何和其他条件。不能一边改变多个量，一边把结果归因于单一因素。

## 每题两层，但不机械套用

本项目采用每题两层：第一层定性操作与判断，第二层定量取数与验证。其他章节先确认教师的层次要求。

第一层提出可见目标，允许失败与修正，不提前要求长公式。保存学生的观察和判断；操作成功只表示完成动作，不表示理解。第二层继承同一条冻结状态，显示量名、单位和计算关系，允许修改算式，再请学生解释验证了什么。两层内容分开保存。

## 科学表述与数值

- 区分真实测量、历史数据、教学重建、现代模拟。理想平行板需要声明忽略边缘效应；有限带电球不能直接称为导体。
- 统一模型内部单位，界面明确换算。mm、pC、fN、V、eV 的换算不能隐含在图形缩放中。
- 屏幕箭长若经压缩就标为示意，不能按长度比读取物理量。电势差用等势线与端点电势，力的方向用受力箭头；选择直接服务目标的图。
- 相机正投影不改变隐藏坐标；将运动限制在某平面属于题目条件，须单独说明。
- 数值答案依据记录时的完整状态。误差阈值应匹配量纲和积分精度，近零时用合理绝对误差；不能用过大绝对容差掩盖相对错误。
- 核验至少选一种与界面计算不同的依据，如解析特例、守恒量、极限、对称性或独立积分。不要把同一函数调用两次当作独立证明。

## 学生证据

导出至少保留题目、模型与单位、固定条件、图形状态、第一层判断、第二层算式和答案、核对结果、解释与批注。老师可检查学生如何从观察过渡到关系式。仅用关键词匹配不得标为概念理解评分。
