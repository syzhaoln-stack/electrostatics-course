# 样式与视觉语言

## 本项目的课堂样式基线

白底书页、深色文字、衬线标题、无衬线操作区、等宽数值。图是页面主体，右侧是当前动作和解释。避免把教材变成同时展开的仪表盘。

| 用途 | 示例值 | 约定 |
|---|---|---|
| 纸色 | #fffefa | 页面背景 |
| 正文 | #243c33 | 标题、主要文字 |
| 次要文字 | #66756d | 说明，勿承载唯一重要线索 |
| 主动作 | #286455 | 一个主要按钮、当前层 |
| 操作对象／路径 | #ae701c | 拖动柄和同一条路径使用一致颜色 |
| 对照路径 | #2d7895 | 配合虚线，不能只靠颜色区分 |
| 分隔 | #d9dfd5 | 轻边框，少用卡片阴影 |

可复制 [textbook-theme.css](../assets/textbook-theme.css) 作为新的章节样式起点。数值范围和字体应按投屏距离调整；颜色不是学科固定含义。

## 布局与字号

桌面示例为主图 + 360–400 px 任务栏，间距约 24 px；正文 16–18 px、说明 13–14 px、主标题 24–30 px。在真实教室投屏检查标注，不能只看桌面截图。

本项目设备验收是 1366×768 与 1920×1080，用户要求不投入移动端测试；这只是本项目约定。迁移章节先确认设备。窄屏可堆叠，但不能因此宣布完成手机交互验证。

## 图中的含义

目标与当前物理状态采用不同位置与文字标记。量纲直接贴近数字；A/B 等点名和颜色长期一致。连续色表示电势等标量时附颜色含义或色标；等势线标电势值，不能让它看成场线。

三维只用于必要空间关系；二维采用同模型正投影，标明投影与剖面的区别。记录图保留关键几何、读数和标注，不能换成丢失关系的简略示意。浮层、标签和控件避免覆盖端点、箭头或刻度。

固定点可用描边标记，拖动点使用填色、抓手文字和足够命中范围。焦点可见，错误与成功同时用文字表达。先减去不服务当前概念的装饰，再增加说明。
