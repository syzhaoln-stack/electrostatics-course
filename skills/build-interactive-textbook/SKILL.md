# 从教学讨论到可解题的交互教材

本工作流从静电场教材的真实制作交流与 2026-10-21 教师研讨中提炼，首次整理于 2026-10-22。不是原项目一开始就使用的 Skill，也不表示已在其他章节验证过学习效果。

## 按任务读取支持资料

- 整理录音、资料和设计依据：[调研与证据](references/research-and-evidence.md)。
- 确定教学契约与模型要求：[教学与模型标准](references/teaching-standard.md)。
- 设计两层任务、反馈与记录：[交互思路与状态](references/interaction-design.md)。
- 统一页面与图形样式：[视觉语言](references/visual-language.md)，可复制 [CSS 基线](assets/textbook-theme.css)。
- 验收、协作包与网站更新：[验证、打包与发布](references/verification-delivery.md)。

按需读取，不要求每次修改都重复整套流程。上述标准是制作约定，不冒充正式行业标准；静电案例不能代替下一章的课程依据。

## 先明确一张图要教什么

读取已有教材、课程目标、题目和可用模型。把录音原话、教师已确认要求、作者新设想、实现建议分开；记录可回查的段落或时间。保留教师已有二维资源；是否使用三维，取决于空间关系是否是理解障碍。

用 [章节输入与逐图反馈模板](references/chapter-brief.md) 收集缺失信息。已能推断的内容直接形成可审阅样板；没有原题时使用清楚标记的自编教学样题，不能称为指定教材原题。

每张交互图建立简短契约：教学目标、已知与所求、允许操作的量、固定条件、屏幕读数的量纲、学生需要提交的理解证据。避免只写“增强交互”或“做得漂亮”。优先做一条完整流程，再根据教师反馈扩展同章资源。

## 将图、题和计算接在一起

- 明确“先定性、再定量”指题目之间还是同一道题内的两个层次。当前教师确认的是每题两层：先操作、判断，再用同一条记录计算验证；保留第一层的观察，不被第二层作答覆盖。目标提示与实际物理箭头分开放置，不能依赖重叠颜色辨认。
- 用渐进展开控制信息量。首屏只强调当前概念、一张主图和一个主要动作；取数后才出现计算，计算后才出现解释。图形、记录图使用同一个区域切换，避免上下重复图让学生分心。参数、其他方向、核验与资料按需展开；一维概念不要默认同时展示横竖两个方向的同类控制。
- 三维样板提供一键二维正投影，默认只留本题需要的主方向；其他投影放进进阶选项。切换只改相机，不把隐藏坐标设为零；保留物理状态、已取数据和作答，返回三维恢复原视角。明确投影不等同剖面。
- 让主图直接表现当前概念：电势差优先用等势线与端点电势读数，不让力箭头抢占主线。先用平行板等简单模型看清关系，再迁移到双球等复杂模型；比较路径无关性时固定端点，只允许改变路径。
- 让题目对应图中可识别的物体与变量。拖动改变什么、哪些量固定，要可见；精确原题需要锁定已知条件或在取数时冻结整组状态。
- 为学生保留“操作 → 取数 → 组式 → 计算 → 解释”的路径。提示可以分层给，不能让一个动画自动播放完就等同完成学习。
- 数据进入计算器时带物理量名和单位。支持直接取数；手动输入、批量粘贴和拖放可作为补充。明确批量数值顺序和单位转换；不要静默猜测。
- 计算器使用受限数学解析器，不执行任意输入代码。表达式、代入值、单位和答案对应同一组图形状态；图继续移动时，应明确旧记录仍然有效但不是当前读数。
- 记录图优先保留原交互模型的放大正投影与关键标注，避免换成丢失空间关系的过简示意图。明确冻结时间，确保记录图、取数状态与作答一致。
- 画图应服务于推理，例如分量、受力方向、积分路径或截面。二维投影不冒充三维剖面；数值计算依据物理状态，不依据屏幕箭头长短。
- 数值正确、动作完成、概念解释是不同证据。可对数值给容差反馈，对模型条件、正负号和单位给提示；不把简单关键词匹配称为理解评分。

## 保持模型可信、交付可接续

读数、图形和答案共享一个物理状态来源；用独立的解析解、守恒量、极限或对称情形核验，避免同一个公式自证正确。说明理想化条件、缩放、离散误差和适用范围。真实史料、教学重建、现代模拟分别标识。

沿用已有教材的字体、配色、叙述顺序和课堂设备要求。对卡顿先复现并记录触发条件，不预先声称知道根因。验证实际拖动、重置、多次取数、错误输入、单位与导出；界面验收依据用户的设备范围，不自行把移动端适配扩大为必做项目。

制作包包含可运行资源、依赖与启动方法、可编辑源码、逐图反馈表、实际制作交流节选、变更和验证记录、后续章节输入示例。只交付运行所需媒体和有用的源文件；绝对路径制作脚本不能直接称作可移植全套生产环境。分享材料排除与教学无关的私聊或电话内容。

后续章节先用本 Skill 形成样板，再请教师核查专业准确性与课堂适用性。参考 [静电场实例与验收方法](references/electrostatics-case.md) 中的可迁移判断，而不是机械复制静电场的参数或模块数。
