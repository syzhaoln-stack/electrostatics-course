第 1 节默认采用严格的点源、无限线、无限平面；规则 XYZ 采样的箭头按固定单调尺度编码强弱，长度和粗细均随场强变化。无限线的场垂直于线，无限平面的场垂直于面。有限线段与圆盘可直接拉动几何尺寸并测误差。路径做功支持真正的 z 位移，空间方向导数通过正交坐标变换计算；辅助曲线和读数对应同一三维模型。

基础、叠加、通量三节加入原创 Manim 三维动画（约 76 秒、57 秒、43 秒），使用豆包“爽快思思＋清爽男大”双学生对话，实际重新生成快语音并缩短停顿。配套 VTT 字幕、可点击问题链、逐句跳转、AI 虚构学生头像和发言高亮；“在模型里试这一问”直接接入章节交互。视频和配音可离线播放。复现源文件见 manim/，媒体说明见 media/lesson-dialogues/README.md。保留粒子束、自由靶、壁面收集、Godot 场景、Blender 资产及原豆包双人音频。首页振荡电荷属于电磁学拓展，不计入静电学核心覆盖。字体与公式资源均本地提供；Noto Serif SC 许可见 `vendor/fonts/`，KaTeX 许可见 `vendor/katex/LICENSE`。

第一节新增五组三维图，紧随相关正文：同一点 +e/+2e、r/2r、同半径不同方向、同电荷不同质量、有限线与无限线。固定示例参数单独标注，图中 E/F/a 的长度比对应物理量比例。主图可等距移动 P，并把当前参数链接到独立实验窗口。正文逐项解释 Q、q、E、F、a、m、e、单位、元电荷的负 19 次方，以及模型近似条件；库仑扭秤与法拉第场观念分别附历史出处。短片保留猜想、测量反例和修正过程。

## 本地课堂

需要 Node.js，无需安装 npm 依赖。

```text
npm test
npm run build
node serve.mjs --directory dist --port 4174
```

打开 http://127.0.0.1:4174/ 。Windows 可双击 `启动本地课堂.cmd`。新版默认用 4174，原实验版可继续使用 4173。

`npm run package:local` 生成 `local-release`。解压后同样需要 Node.js；图形库、照片、模型、视频和音频均本地提供，外部参考链接需要联网。不要直接双击 HTML：浏览器模块需要本地 HTTP 服务。

## 模型与核验

- `foundation-physics.js`：点源、有限线段和圆盘。计算接口采用 SI，界面标明 mm、pC 等单位。小段库仑求和独立验证有限线段解析式。
- `symmetry-physics.js`：球面、圆柱、薄盒曲面积分独立于解析总通量。定理普遍有效，从积分提出 E 依赖对称性。
- `paths-physics.js`：路径上的 qE·dr 与端点电势差分别计算。闭路允许中途非零功；局部微分保留有限步长误差。
- `conductor-physics.js`：孤立带电球、均匀外场中的中性球。导体内部总场为零，表面等势、切向场为零；与绝缘带电球模型严格区分。
- 所有双源等势层显示 V₁+V₂ 与 U=qV。沿面运动受约束，W=0 不等于 F=0。仅电场做功的自由释放才使用 W=ΔK。
- 通量页使用有限均匀带电绝缘球，跨界时按包入体积分数计算 Q内；不混同理想点源落在积分面上的奇异情况。
- 本教材覆盖大纲概念及代表性求解模型，不宣称逐一实现任意导体边界问题。空腔含电荷、多导体耦合、复杂接地边界需另行求解。
- 事故事实与照片来源见各案例和 `risk-sources.md`；动画是定性机制示意，不能代替调查结论或安全设计。

`npm test` 运行物理测试；浏览器另验桌面/390px 手机布局、拖拽、换电荷、播放回看、读数与章节链接。计算正确不等于学生已经掌握，教学还需评价解释与迁移。

GitHub Actions 在 main 更新后测试、构建并发布 Pages。QA 页面不进入构建。原实验详细模型说明保留于 `legacy-model-notes.md` 和 `physics-notes.md`；旧运行入口仅作版本记录。

公开参考：[OpenStax University Physics Volume 2，第 5—7 章](https://openstax.org/books/university-physics-volume-2/pages/5-introduction)。各节页末有相关章节链接。正文根据物理定义独立编写，未复制原教材整段内容。
